# mako7studio

**高校2年生。DeepSeek Harness（DSH）のプラグインを書いています。**
作ったものは全部無料・MIT ライセンスで公開しています。

---

## 作っているもの

DeepSeek Harness は AI エージェントを動かすハーネスで、プラグインで機能を足せます。
僕が作っているのは、**エージェントが実際に困る場面を減らすためのもの**です。

| リポジトリ | 何をするか |
|---|---|
| [dsh-plugins](https://github.com/makochannel1234567890-boop/dsh-plugins) | DSH プラグイン集（本体）。並列オーケストレーション、長考モード、スマホ進捗など |

### 特に関心があること

- **並列オーケストレーション** — 1 つの依頼を複数セッションに分けて走らせ、
  最後に統合と検証まで自動でやる。「分けると速いが、まとめるのが難しい」を解く
- **思考の省略を打ち消す** — モデルは放っておくと早すぎる結論に飛びつく。
  独立性の高い視点を別セッションとして立て、出てきた選択肢を全部分類させてから
  先に進ませる、という仕組みを作った
- **外出先から作業を見守る** — PC の前を離れても、スマホで進捗が見える状態
