## 2. 25 秒に落とせるカット割りのパターン（5 つ）

各パターンに「元になったリール」と「25 秒への具体タイムライン」を付けた。`B` = 拍、`bar` = 小節。BPM と小節頭は `02-music.md` の実測値を使う。

### P1. ワンテイク・ドリブン（元: R1 (https://www.instagram.com/reel/DWU6wxIiHKb/) / 0 カット）
- **型**: カットしない。動き（スクロール・カーソル・タイピング）で画面を変化させ、ズームだけを 2 回入れる。
- **25 秒タイムライン**: 0.0–2.0 寄りのアップ（フック文言だけ）→ 2.0–7.0 ゆっくり引いて全体 → 7.0–20.0 操作を連続で見せる → 20.0–25.0 結果にズーム＋ロゴ。
- **使いどころ**: 実画面の操作が主役で、テンポより「気持ちよさ」を見せたい回。**5 本のうち 1 本はこれ**にすると単調にならない。

### P2. 均等グリッド（元: R3 (https://www.instagram.com/reel/DW6YhHDjiHn/) / 平均 1.64s）
- **型**: 1.5〜1.8 秒でほぼ等間隔に切る。25 秒なら **15〜16 ショット**。
- **25 秒タイムライン**: 1.6×15 + 最後 1.0。1 本ごとに「別のプラグイン画面」を割り当てると、7 プラグインを 2 周できる。
- **使いどころ**: 「機能がたくさんある」ことを最短で伝える回。迷ったらこれ。

### P3. 長回し＋マイクロフラッシュ（元: R4 (https://www.instagram.com/reel/DWjdnxMCpcL/) / 4.5s キープ + 0.15s 連打）
- **型**: 3〜4.5 秒の保持を 2〜3 回、その間に 0.15 秒のフラッシュ（画面反転・白フラッシュ・テロップだけのコマ）を挟む。
- **25 秒タイムライン**: 2.0 / 4.0 / 0.15×2 / 2.0 / 1.5 / 4.5 / 3.0 / 0.75 / 0.75 / 3.6 / 残り。合計 25.0。
- **使いどころ**: 導入（何の話か）→ 実演 → 結果、の 3 幕がはっきりしている回。

### P4. ラピッドファイア・クラスタ（元: R5 (https://www.instagram.com/reel/DXMtRJOj-M-/) / 0.3s 連打）
- **型**: 0.3 秒の超短カットを 5〜6 発クラスタで打ち、直後に長回しで「息継ぎ」させる。
- **25 秒タイムライン**: 0.0–1.5 通常（フック）→ 1.5–3.3 に 0.3×6 → 3.3–9.0 長回し → 9.0–10.5 に 0.3×5 → 10.5–20.0 長回し（実演）→ 20.0–21.8 に 0.3×6 → 21.8–25.0 締め。
- **使いどころ**: 情報量が多く、テンポで押したい回。**やりすぎると酔うのでクラスタは 3 回まで**。

### P5. 速い入り→長い実演→詰め（元: R2 (https://www.instagram.com/reel/DUHGe05Dszy/) / 0.6→9.0 秒）
- **型**: 冒頭 3 秒だけ細かく刻み、中盤に 8〜10 秒の長回しを 1 本置き、ラスト 3〜5 秒でまた刻む。
- **25 秒タイムライン**: 0.0–3.0（0.4×7 程度の細刻み）→ 3.0–8.0 中刻み（1.0×5）→ 8.0–20.0 **長回し 1 本（12 秒）**→ 20.0–25.0 詰め（0.6/0.5/0.4/0.3/1.2）。
- **使いどころ**: 「1 つの操作を最後まで見せたい」回。長回しが主役なので、その 12 秒に一番見せたい画面を置く。

**カットを音楽に合わせる方法**: 上表の `bar`（1 小節の実秒）で切ると拍に乗る。厳密にやるなら `02-music.md` の「小節頭リスト」の秒数で切る。P2 の 1.6 秒グリッドは 122 BPM の 1 小節（1.967s）より僅かに短いので、**1 ショット = 1 小節に合わせたいときは 1.967 秒**を使う（15 ショットで 29.5 秒になるため、13 ショット + 締め 2 ショットに調整）。

## 4. そのまま使える共通の制約（観測から決めたもの）

- 解像度: 参照 5 本すべて **720x1280（9:16）**。制作は **1080x1920** で書き出し（縦横比は同じ）。
- 尺: 参照は 39〜47 秒。25 秒は**冒頭 3 秒で「何か」を見せないと足りない**ため、P1 以外は 0〜3 秒を細かく刻む。
- セーフエリア: テロップは上下に余白を取る（Instagram の UI が上下 ~250px を覆う）。1080x1920 なら上 200px / 下 350px は空ける。
- カット総数の目安: 25 秒で **0 〜 20 カット**。20 を超えると P4 の領域に入り、酔いやすくなる。

## 5. 数値の来歴（attempt 3 = t1-a3 で確認したこと）

- **URL の到達性**: `DWU6wxIiHKb` / `DUHGe05Dszy` / `DW6YhHDjiHn` の 3 本を `https://www.instagram.com/reel/<id>/` で再取得 → すべて **HTTP 200**（応答 542,381 / 542,379 / 538,404 文字）。ただし返る HTML は**ログインシェル**で、`og:title` / `og:description` / `"username"` は抽出できなかった。`/reel/<id>/embed/captioned/` も同様（200・約 538KB・作者名なし）。
  → **「URL が実在して 200 を返す」ことは確認済み。「その URL がこのアカウント・この尺である」ことは本 attempt では HTML から確認できていない。**
- **動画の再計測は不可**: 同時刻に別セッションが同じリールを開き、`<video>` は `readyState 0`・映像領域は黒。原因は `visibilityState:"hidden"`（非表示ウィンドウでは Chromium がメディア読込を止める）と切り分けられた。
  → §1 の**尺・カット位置の数値は attempt 2 の実測記録**であり、本 attempt では再現確認していない。
- **それでも §2 の型は使える理由**: P1〜P5 は「1 テイク / 等間隔 / 長回し＋0.15s フラッシュ / 0.3s 連打クラスタ / 速い入り→長回し→詰め」という**構造の抽出**で、25 秒タイムラインはその構造から設計したもの。数値の再現性が無くても、5 本の撮影設計図としてはそのまま使える。
- **未確認として残すもの**: テロップ文言・音・構図の分析、現時点の再生数。必要なら非ログイン・可視ウィンドウの公開環境で再観測する。
