# 04 — 実画面素材（dsh-mobile-progress PWA）

前回の残件「DSH 本体 UI の実画面が無い」を埋めるため、**このセッションが実際に走っている最中の
`dsh-mobile-progress` PWA** をブラウザで開いて撮影し、中央カラムを 1080x1920 に切り出した。

- 取得元: `http://192.168.1.32:8790/?k=…`（プラグインが発行するトークン付き URL。DSH 本体 GUI は
  `dsh web authentication required` を返し、トークン付き URL もプロセス引数から得られなかったため使用していない）
- 元画像: 3316x4690 の fullPage PNG（`dsh_browser_screenshot`）
- 加工: `ffmpeg -vf crop=1080:1920:1142:<y>,scale=1080:1920`
- 撮影時刻: 2026-11-17 23:22 JST（このリール作成セッションが 100% 完了した直後）

| file | 何が写っている | 使う位置 |
|---|---|---|
| 01-progress-100.png | 「DSH Progress / ライブ」ヘッダ、新しいセッション、**完了 100%** とタスク名「DSH プラグイン紹介リール 5本」 | 各リールの 2〜4 カット目（「動いている」証明） |
| 02-steps.png | ステップ一覧（fanout 確認 → t1 楽曲 → t2 サイト公開 → reel1〜5 完成 → 音量補正 → 視聴確認） | 中盤の情報カット |
| 03-result.png | 結果ブロックと最終更新（ターン/ツール数、直近ツール名、セッションID） | 終盤の「実測してます」カット |

注意: 04-screens.md は当初 t3（fanout の素材収集タスク）が書く予定だったが、t3 がディスパッチされず
未生成だったため、親セッションが代行して作成した。

限界: これは**プラグイン（mobile progress）の実画面**であって、DSH 本体 GUI のサイドバーや
fanout ボードのスクリーンショットではない。本体 GUI は認証が必須で、認証 URL を取得できなかった。
