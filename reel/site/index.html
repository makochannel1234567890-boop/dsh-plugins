dsh-fanout

dsh-fanout · v0.3.0

1 セッションを複数の並行ワーカーに振り分け、重さで配分。最後に統合用セッションが統合・検証・ビルドまでやる。

  • 並行ワーカーへの自動配分
  • 統合役（統合＋検証＋ビルド）の自動起動
  • 早すぎる結論を潰す divergence_check
  • 左サイドバーのボード／Web スライダー 2 本

02 / 06

dsh-mobile-progress

@local/dsh-mobile-progress · v0.3.0
インストール時のフォルダ名は dsh-mobile-progress

エージェントの進捗をスマホの PWA で見る。Host プラグインが SSE で進捗バーを配信する。

  • todo_write の自動ミラー
  • スマホでワークスペースを選んで新セッション開始
  • 最終アシスタント結果も同じ画面に
  • cloudflared で LAN 外から・配信中はスリープ抑止

03 / 06

dsh-deliberation

dsh-deliberation · v0.1.0

承認つきの、範囲の決まった長考モード。

  • 始める前にユーザーの承認を取る
  • 任意で Git 作業ツリーに隔離
  • ラウンドを自動継続（予算・停滞・ユーザー優先のガード付き）
  • 新しいメッセージでいつでも止まる

04 / 06

dsh-emulator-lab

dsh-emulator-lab · v0.1.0

サイドバーから Android AVD / iOS Simulator を起動し、低スペック端末の FPS を見積もる。

  • 端末プロファイルと SoC を選択
  • 決定論的な SoC モデルで推定（INT8 TOPS・メモリ帯域・CPU/GPU スコア・熱予算）
  • 「推定」であることとボトルネックを明示

05 / 06

dsh-social-desktop-agent

dsh-social-desktop-agent · v0.1.0

allowlist 内のソーシャル Web 閲覧と、ローカルデスクトップの観察・操作。既定は最小権限。

  • 明示的なスコープ付与＋host / app allowlist
  • いいね・フォロー・DM・投稿・コメントは恒久拒否
  • 電源操作は三段ゲートで既定 dry-run
  • 追記専用の監査ログ＋kill switch

06 / 06

dsh-builtin-browser-localfix

package.json なし（パッチ配布）

内蔵ブラウザを「1 ターンの終わりに、そのタスクのブラウザセッションを閉じる」ようにするパッチ。

  • turn-cleanup.patch ＋ 適用スクリプト apply.ps1
  • ターンをまたいでタブが残らない／タスクごとに独立
  • 反映には DSH の再起動が必要
  • DSH_BROWSER_KEEP_TABS=1 か config で無効化できる

原文

各 package.json の
description

dsh-fanout
Fan one session out into several parallel worker sessions for large asymmetric jobs, auto-start an integrator that merges + verifies + builds, run an unanchored expansion gate against premature narrowing, show every run's progress on a left-sidebar board, and dial the cost with two Web sliders.
dsh-mobile-progress
Live agent progress on the phone as an installable PWA: a Host plugin serves a progress bar over SSE, starts a new DSH session from a workspace chosen on the phone, shows the final assistant result on the same screen, exposes a public HTTPS URL through a cloudflared tunnel (so the phone works off the LAN), and keeps the PC awake while the feed is live.
dsh-deliberation
Bounded extended-deliberation mode for DeepSeek Harness: ask the user for approval, optionally isolate a Git worktree, then auto-continue deep-thinking rounds with budget, stagnation, and user-priority guards.
dsh-emulator-lab
Boot Android AVDs and iOS Simulators from the DSH sidebar and estimate low-end phone FPS from a deterministic SoC model (INT8 TOPS, memory bandwidth and capacity, CPU/GPU scores, thermal budget).
dsh-social-desktop-agent
Let a DSH agent read and interact with allowlisted social web pages and observe/operate the local desktop, under an explicit scope grant, host/app allowlists, a permanent ban on write-type social actions, confirmation-gated power operations, an append-only audit log and a kill switch.
dsh-builtin-browser-localfix
package.json がありません。README.md の見出し「dsh-builtin-browser ローカルパッチ：ターン終了時にタブを閉じる」と、その冒頭説明（内蔵ブラウザに、1 ターンが終わった時点でそのタスクのブラウザセッションを自動で閉じる工程を足したもの）を出典としています。
